# Security Model

Member 1 should define these rules:

```text
1. No secrets in Git
2. Environment variables for credentials
3. Uploaded configs treated as sensitive
4. Strict file validation
5. Size/type limits
6. Authentication for protected operations
7. Authorization for admin functions
8. Audit important mapping changes
9. AI output never trusted blindly
10. No arbitrary command execution from uploaded files
11. No unauthorized network access
12. No production infrastructure testing without authorization
```
